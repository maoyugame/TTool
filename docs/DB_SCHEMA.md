# DB_SCHEMA

## 当前状态

当前项目未确认存在生产数据库 schema。`package.json` 中包含 `mongodb`、`mysql2`、`ioredis` 等依赖，但本文件不据此假设已经有业务数据库模型。

## 维护规则

- 新增数据库、Redis key 空间、持久化结构或迁移方案时，必须更新本文件。
- 涉及数据破坏、迁移、权限或生产数据访问的任务进入 Full Pipeline，并需要明确验收与回滚方案。
- 不得在未确认用途时修改生产数据库、凭据、环境变量或部署配置。
