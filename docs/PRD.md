# PRD

## 当前产品方向

TTool 面向需要高频处理文本、数据、时间、格式化、翻译和本地应用启动的桌面用户，提供一个可扩展的工具平台。

## 已知核心能力

- 指挥官风格启动台与标签工作区。
- 内置工具注册表，新增内置工具以 `src/tools/impl/<id>.tsx` + 注册为主。
- 外部插件系统，支持插件安装、启停、更新、卸载与运行时懒加载。
- 平台适配层，核心逻辑通过 `Platform` 抽象访问桌面能力。
- 深 / 浅色主题与本地持久化。

## 需求维护规则

- 具体需求拆解写入 `docs/TASKS.md` 或 Task Thread 摘要。
- 涉及用户故事、验收标准、范围取舍时优先派发给 Sophia - 产品。
- 涉及 UI/UX 或视觉资源时进入 DesignArt 阶段，并遵守 imagegen-only art gate。

## 待补充

该文件只保留项目级 PRD 总览。新功能 PRD 应按任务粒度补充，避免把 Task Thread 细节长期堆在本文件。
