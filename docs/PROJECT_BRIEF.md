# PROJECT_BRIEF

## 项目概览

TTool 是一个跨平台桌面多功能工具平台，采用指挥官风格启动台 + 标签工作区。当前核心体验包括工具搜索、内置工具运行、第三方应用快捷启动、主题切换、平台感知快捷键与 Electron 桌面能力。

## 已接受能力摘要

- 截图贴图：桌面端内置工具，支持截图、截图并贴图、最近 5 张截图、标注编辑、当前贴图管理和全局快捷键设置。
- 截图贴图工具页采用顶部状态操作栏 + 左最近截图 / 中间标注编辑器 / 右当前贴图三栏工作台；快捷键设置外置到顶部栏中间区域，截图贴图页不再提供单独 `设置` 按钮。
- 普通截图完成后默认写入系统剪贴板，并显示右下角浮窗；用户点击或键盘确认才进入标注编辑器，未操作自动消失；截图并贴图仍直接生成置顶贴图。
- 标注编辑器默认适配图片，支持圆形标注、点选/框选选择、移动/删除选中标注，以及矩形/圆形携带文本。
- 截图能力保持内置工具专用，不暴露给外部插件 SDK。

## 技术栈

- 前端：Vite + React 19 + TypeScript。
- 桌面壳：Electron。
- 插件 SDK：`@maoyugames/ttool-sdk`，源码位于 `packages/sdk/`。
- 插件形态：内置工具与外部插件并存。
