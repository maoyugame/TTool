# TTool 截图贴图快捷键外置与状态操作栏整理

## 目标

根据用户验收反馈，截图贴图工具页顶部栏需要从“左侧状态 + 右侧操作 + 设置入口”调整为“左侧精简状态 + 中间快捷键设置 + 右侧启用与主操作”。右侧 `设置` 按钮取消，快捷键配置直接放到用户红框标注的顶部中间空白区域。

本规格只定义信息架构与交互，不生成视觉资产，不修改业务代码，不改变插件 SDK 边界。

## 顶部栏信息架构

### 左侧：精简状态摘要

保留用户判断当前工具是否可用所需的信息，去掉重复快捷键 chip。

建议结构：

- 第一行：`截图贴图` 标题 + `已启用` / `已关闭` 状态 chip。
- 第二行：环境与权限 chip，最多 3 个：
  - `桌面运行时` / `仅桌面版可用`
  - `权限可用` / `需要权限`
  - `2 个显示器` 或 `未检测到显示器`
- 第三行：最近状态或错误文案，如 `已进入标注`、`截图已取消`、`快捷键被占用，已保留原设置`。

应移除或迁出：

- 左侧不再显示 `截图：快捷键已注册`、`贴图：快捷键已注册` 这类重复 chip；它们由中间快捷键区承载。
- 不展示冗长技术细节；失败时只保留面向用户的错误句。

### 中间：内联快捷键设置区

位于用户红框区域，承载两条快捷键配置：

- `截图`
- `截图并贴图`

每条快捷键使用紧凑行或紧凑卡片，建议字段：

- 左侧 label：`截图` / `截图并贴图`
- 当前组合：kbd chip，例如 `Control+Alt+A`
- 注册状态：小状态点或短 chip，例如 `已注册`、`已停用`、`冲突`、`注册失败`
- 操作：`录制`、`重置`

录制态：

- 点击 `录制` 后，该行组合 chip 变为 `按下新的快捷键`。
- Esc 取消录制。
- 必须保留“至少一个修饰键 + 一个主键”的规则。
- 冲突或注册失败时，在该行下方以短文案显示原因，保留原有效快捷键。

布局建议：

- 宽屏：两条快捷键横向并排，整体居中或偏右，占用顶部栏中间空白区。
- 1366 左右：两条快捷键可横向并排，但按钮和 kbd chip 必须不挤压；必要时每条行内把 `重置` 放到下一行或缩成次要按钮。
- 约 980：快捷键区换到顶部栏第二行，占满可用宽度；状态摘要在上方或左侧，主操作保持右侧/下一行。
- 窄宽度：快捷键区在状态与主操作之间单列堆叠，每条快捷键一行；不得压缩到文字溢出。

### 右侧：启用与主操作

右侧只保留高频动作：

- 启用/关闭开关
- `截图`
- `截图并贴图`

明确移除：

- `设置` 按钮
- 设置 popover/drawer/panel 入口

右侧动作在窄屏下可以换行，但顺序保持：启用开关、`截图`、`截图并贴图`。

## 状态与操作栏整理原则

- 顶部栏不是状态墙。左侧显示“当前能不能用”和“最近发生了什么”；中间显示“快捷键怎么配”；右侧显示“现在要做什么”。
- 快捷键注册详情只在中间快捷键区显示，不在左侧重复。
- 错误优先级高于普通状态。若存在最近错误，左侧第三行显示错误；快捷键行内显示对应行的短错误。
- 功能关闭时：
  - 左侧显示 `已关闭`；
  - 中间快捷键状态为 `已停用`，仍允许编辑；
  - 右侧主操作按钮 disabled 或保持当前既有禁用策略；
  - 全局快捷键不生效。
- 桌面能力不可用时：
  - 左侧显示 `仅桌面版可用`；
  - 中间快捷键区仍可展示配置但注册状态为不可用；
  - 主操作 disabled。

## 与现有页面关系

主体三栏保持不变：

- 左侧最近截图。
- 中间 AnnotationEditor。
- 右侧当前贴图。
